
## Colors

This theme uses soft, waterlike colors

/* Series / model colours (c1–c5) */
  --waterlily-blue-light:   #A1D3FF;  /* c1 */
  --waterlily-aqua:         #C5E7E7;  /* c2 */
  --waterlily-blue:         #85B6EA;  /* c3 */
  --waterlily-green:        #C6F0A6;  /* c4 */
  --waterlily-lilac:        #D4C0EE;  /* c5 */

  /* Darker series tints for text and strokes on light backgrounds (k1–k5) */
  --waterlily-blue-light-ink: color-mix(in oklab, var(--waterlily-blue-light) 55%, #2E2F2F);
  --waterlily-aqua-ink:       color-mix(in oklab, var(--waterlily-aqua) 55%, #2E2F2F);
  --waterlily-blue-ink:       color-mix(in oklab, var(--waterlily-blue) 55%, #2E2F2F);
  --waterlily-green-ink:      color-mix(in oklab, var(--waterlily-green) 55%, #2E2F2F);
  --waterlily-lilac-ink:      color-mix(in oklab, var(--waterlily-lilac) 55%, #2E2F2F);



## Shapes 

use rounded shapes with thin borders

you can get inspiration from the waterlily shapes in elements folder. do not paste them exactly but use them to get inspiration on how to shape the report. 

## Fonts 

Default font is Kedebideri in black font. 
you can also use Montserrat. 

Avoid bold fonts instead play between light, medium, normal, semi bold.
